# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-23

### Added
- Initial release of FastTouch
- Native Win32 `WM_POINTER` multi-touch digitizer interception
- Pressure sensitivity (0–255) and contact patch bounding-box dimensions
- 10+ simultaneous finger contact tracking
- Standardized FastJava ecosystem module
